# Pocket World

自分の部屋を3Dで忠実に再現し、Web上で探索できる個人ポートフォリオをつくるプロジェクトです。部屋にあるオブジェクトをクリックすると、自分の活動や制作物についてわかるページへ移動できる体験を目指します。

## 最初の目標

まずは実際の部屋を忠実に再現することから始めます。家具や小物の形状・寸法・色・素材感と配置を丁寧につくり込み、完成した部屋をWebに落とし込みます。

既存の簡略模型は探索や操作を試すための試作です。今後は、個別に制作したBlenderアセットを組み合わせて部屋を構築します。

## 制作の順序

1. **資料を整理する**：写真や実寸から、家具・小物の一覧と特徴を整理します。不明な寸法や見えない面は推定箇所として記録します。
2. **各オブジェクトを制作する**：camera-to-blenderで実物の写真からモデルを生成し、Blenderで形状・細部・素材を整えます。机、椅子、ベッド、収納、PC、本などを一つずつきれいに仕上げ、個別の `.blend` ファイルとしてアセットフォルダに保存します。
3. **部屋の枠を制作する**：オブジェクトの制作後に、床・壁・天井・窓・入口などを実際の寸法や位置関係に合わせて制作します。
4. **オブジェクトを配置する**：制作済みのアセットを部屋に配置し、写真と照らし合わせて位置・向き・大きさ・照明を調整します。
5. **Webに落とし込む**：完成した部屋とアセットをWeb向けに書き出し、ブラウザでの見た目と描画負荷を調整します。
6. **活動紹介ページにつなぐ**：各オブジェクトにクリック操作と遷移先を設定し、作品・開発・学び・プロフィールなどを紹介するページへ移動できるようにします。対応する活動内容やURLは制作時に決めます。

## オブジェクト制作に使うツール

[camera-to-blender（Camera to 3D）](https://github.com/ahujasid/camera-to-blender) を各オブジェクトのモデル制作に使用します。

公式READMEでは、撮影した写真から3Dモデルを生成し、Blenderへ送るワークフローが案内されています。必要なものはPython 3.10以上、Blender 3.0以上、Tripo3D APIキーです。背景除去用のGemini APIキーは任意で、スマートフォンから利用する場合はHTTPS接続用にngrokを使用します。

このプロジェクトでは次の流れで使用します。

1. 対象の家具・小物を撮影し、実寸と特徴も記録する。
2. camera-to-blenderでモデルを生成してBlenderへ取り込む。
3. 実物と比較し、形状・寸法・見えない面・素材・テクスチャを修正する。
4. 単位・スケール・向き・原点をそろえ、配置しやすい状態に整える。
5. 完成したオブジェクトを専用の `.blend` ファイルとして保存する。

写真からの生成結果を出発点に、忠実な再現に必要な調整をBlenderで行います。ツールの導入・接続・モデル生成はこれから行います。セットアップの詳細はリンク先のREADMEを参照してください。APIキーは `.env` で管理し、公開ファイルやGitに含めません。

## アセットの管理方針

今後は以下の構成で管理します。これは予定の構成で、個別アセットはこれから制作します。

```text
assets/
  objects/
    desk/
      desk.blend
    chair/
      chair.blend
    bed/
      bed.blend
    ...
  room/
    room-shell.blend       # 床・壁・天井・窓・入口
    room-assembled.blend   # オブジェクトを配置した部屋
```

- 各オブジェクトの編集可能な制作元を個別の `.blend` ファイルとして残します。
- 必要なテクスチャはアセットと一緒に管理し、参照切れを防ぎます。
- 単位とスケールを統一し、配置しやすい原点・向きを設定します。
- 部屋全体のシーンは、個別アセットを参照して構築する方針です。
- Web向けの書き出し形式と読み込み方法は、制作したアセットを踏まえて決定します。

## 現在の実装

素のJavaScript・HTML・CSSと独自のWebGL描画による試作があります。外部パッケージは不要です。展示文章は主にサンプルで、今後実際の活動内容へ差し替えます。

- 部屋・西早稲田キャンパスの模型表示、回転・ズーム。
- 展示スポットと本棚からの詳細閲覧。
- 昼・夕の照明切り替え。
- 一人称移動、家具や壁との衝突判定、物の持ち上げ・読書・返却の実装。

**現在の `index.html` は模型用の `app.js` を直接読み込むため、初期表示は模型ビューです。** 一人称と模型を切り替える `boot.js` はありますが、HTMLには未接続です。

現在のWeb表示はGLBを読み込まず、JSONなどから形状を組み立てています。Blenderで編集した内容をWebに自動反映する仕組みはまだありません。今後の個別アセットを使う構成に合わせて整備します。

## 起動

Node.jsが必要です。追加パッケージのインストールは不要です。

```powershell
cd pocket-campus
npm run dev
```

すでに `pocket-campus` 内にいる場合は `npm run dev` のみ実行します。起動後、<http://127.0.0.1:4173> を開きます。ES Modulesとfetchを使うため、HTTPサーバー経由で閲覧してください。

- `/?scene=room`：現在の部屋の模型表示。
- `/?scene=campus`：西早稲田キャンパスの模型表示。

## 現在のファイル構成

| パス | 役割 |
| --- | --- |
| `dist/index.html` | Webページの入口 |
| `dist/app.js` | 部屋・キャンパスの模型表示と展示UI |
| `dist/boot.js` | 一人称・模型の切り替え処理（HTMLには未接続） |
| `dist/inside.js` | 一人称操作、物の持ち上げ、読書 |
| `dist/room-renderer.js` | 一人称ビューの描画、素材、照明 |
| `dist/room-physics.js` | 移動、衝突判定、物の選択 |
| `dist/room-math.js` | カメラと行列演算 |
| `dist/room.json` / `dist/campus.json` | 展示文章や配置データ |
| `dist/room-geometry.json` | 現在の部屋の生成済み形状 |
| `build-room.mjs` | 現在の部屋の形状生成 |
| `create-room.py` / `create-model.py` | Blenderモデルの生成・書き出し |
| `models/` | 既存のBlenderファイルと参考画像 |
| `server.mjs` | ローカルHTTPサーバー |
| `verify.mjs` / `verify-inside.mjs` | 既存実装の検証 |
| `VALIDATION.md` | これまでの検証記録 |

`dist/` には直接編集する実装ファイルも含まれます。`models/` の既存モデルは試作として残し、今後の個別アセットは `assets/` に整理します。

## 既存の生成・検証手順

現在の簡略模型を再生成する手順です。

```powershell
node build-room.mjs
blender --background --python create-room.py
blender --background --python create-model.py
```

Blenderのコマンドは実行ファイルがPATHに登録されている環境で使用できます。部屋の模型は `build-room.mjs` が生成した形状をWebとBlenderで共有します。

```powershell
npm run check
node verify.mjs
node verify-inside.mjs
```

検証スクリプトは数値、操作の状態遷移、模擬DOM・WebGLでの描画処理などを確認します。実際のブラウザやGPUでの画質確認は別途必要です。`models/` のプレビュー画像はBlenderの参考レンダーです。

## キャンパスの試作

西早稲田キャンパスの模型も既存の試作として含まれています。現在の制作の最初の目標は、自分の部屋の忠実な再現です。

キャンパス模型は非公式のコンセプトモデルで、配置や縮尺は実測に基づいていません。参考：[早稲田大学の西早稲田キャンパス案内](https://www.waseda.jp/top/access/nishiwaseda-campus)。
